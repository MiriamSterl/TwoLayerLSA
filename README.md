Code used to produce the figures in the paper ["The joint effects of planetary $\beta$, topography and friction on baroclinic instability in a two-layer QG model"][https://www.cambridge.org/core/journals/journal-of-fluid-mechanics/article/joint-effects-of-planetary-boldsymbolbeta-topography-and-friction-on-baroclinic-instability-in-a-twolayer-quasigeostrophic-model/C9152401E7FD3736FBA923C0360C88C0] by Sterl et al. (2025).

In `linear_stability_analysis.ipynb`, all the figures in the manuscript are made. The calculations for creating Figures 3-5 are done with the code in the file `theory_nonzonal.py`, which is called in `theory.sh` (showing which parameters were used for the data that is plotted).
